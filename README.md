## Prérequis

Avant de commencer, assure-toi d'avoir :

- Un Android **5.0 ou supérieur**
- **Termux** installé depuis [F-Droid](https://f-droid.org/packages/com.termux/) (pas le Play Store — version obsolète)
- Au moins **6 Go d'espace libre**
- Une connexion internet stable

> **Note :** N'installe pas Termux depuis le Google Play Store. La version F-Droid est à jour et maintenue.

---

## Installation

### Étape 1 — Ouvrir Termux et autoriser le stockage

```bash
termux-setup-storage
```

### Étape 2 — Télécharger le script

```bash
curl -sL https://raw.githubusercontent.com/urueshzfowblauey-collab/kali-termux-/main/kali-setup.sh -o kali-setup.sh
```

### Étape 3 — Rendre le script exécutable et le lancer

```bash
chmod +x kali-setup.sh
bash kali-setup.sh
```

> **Pourquoi ne pas utiliser `bash <(curl …)` directement ?**
> Cette syntaxe pipe stdin sur le réseau — les menus interactifs ne peuvent plus lire tes réponses. Télécharge toujours le script d'abord.

## Menu d'installation

Au premier lancement, tu arrives sur le menu d'installation :

```
╔══════════════════════════════════════════╗
║          MENU INSTALLATION               ║
╚══════════════════════════════════════════╝

[2] Quitter
```

Choisis **[1]** puis suis les étapes :

| Étape | Description |
|-------|-------------|
| Connexion | Vérifie l'accès à internet |
| Architecture | Détecte automatiquement `arm64`, `armhf`, `amd64` |
| Espace disque | Contrôle qu'il reste au moins 6 Go |
| Type de rootfs | Tu choisis entre Nano, Minimal ou Full |
| Mise à jour Termux | Optionnelle, recommandée |
| Dépendances | Installe `proot`, `curl`, `tar`, `xz-utils` |
| Téléchargement | Rootfs depuis les serveurs Kali |
| Vérification SHA256 | Intégrité du fichier téléchargé |
| Extraction | Décompression dans `~/kali-fs` |
| Config initiale | `apt update` + paquets de base |

### Choisir le bon rootfs

```
[1] Nano    (~200 MB)   → ultra léger, terminal seul
[2] Minimal (~140 MB)   → base minimaliste
[3] Full    (~2 GB)     → environnement complet avec outils
```

## Menu principal

Après installation, le script affiche le menu principal :

```
╔══════════════════════════════════════════╗
║            MENU PRINCIPAL                ║
╚══════════════════════════════════════════╝
[1] Lancer Kali Linux
[2] Mettre a jour Kali
[3] Installer outils supplementaires
[4] Backup
[5] Restaurer backup
[6] Snapshot
[7] Restaurer snapshot
[8] Desinstaller Kali
[9] Quitter
```

### Détail des options

**[1] Lancer Kali Linux**
Démarre un shell Kali complet via `proot`. Tu es root dans l'environnement Kali.

**[2] Mettre à jour Kali**
Lance `apt update && apt upgrade && apt autoremove` à l'intérieur de Kali.

**[3] Installer outils supplémentaires**
Installe automatiquement :
`nmap` · `hydra` · `sqlmap` · `aircrack-ng` · `curl` · `wget` · `git` · `python3` · `metasploit-framework`

**[4] Backup**
Crée une archive `.tar.gz` de `~/kali-fs` dans ton home Termux. Les caches et logs sont exclus pour gagner de la place.

**[5] Restaurer backup**
Restaure un backup en entrant son chemin complet. Une confirmation est demandée avant d'écraser `kali-fs`.

**[6] Snapshot**
Crée un snapshot horodaté dans `~/kali-snapshots/`. Utile avant une manipulation risquée.

**[7] Restaurer snapshot**
Liste les snapshots disponibles et permet d'en choisir un à restaurer.

**[8] Désinstaller Kali**
Supprime `~/kali-fs` et les launchers `kali` et `kali-setup` de `$PREFIX/bin`.

## Structure des fichiers

```
~/ (home Termux)
├── kali-fs/              ← environnement Kali complet
├── kali-setup.log        ← logs horodatés de toutes les opérations
├── kali-snapshots/       ← snapshots créés via le menu [6]
│   └── snap-20240601-143022.tar.gz
└── kali-backup-*.tar.gz  ← backups manuels via le menu [4]

$PREFIX/bin/
├── kali                  ← launcher rapide
└── kali-setup            ← ce script (copié automatiquement)
```

## Dépannage

**Le script se ferme immédiatement au démarrage**
→ Vérifie que tu l'as téléchargé avec `curl` et que tu l'exécutes avec `bash kali-setup.sh`, pas via un pipe.

**Erreur "Espace insuffisant"**
→ Il faut au moins 6 Go libres. Libère de l'espace ou utilise le rootfs Nano.

**Téléchargement qui échoue**
→ Le script bascule automatiquement sur le miroir de secours. Si les deux échouent, vérifie ta connexion.

**SHA256 invalide**
→ Le fichier téléchargé est corrompu. Le script le supprime et affiche une erreur. Relance l'installation.

**`proot` introuvable**
→ Lance manuellement : `pkg install proot`

**Voir les logs**
```bash
cat ~/kali-setup.log
```

```bash
bash kali-setup.sh

```

```bash
rm -rf ~/kali-fs
rm -f $PREFIX/bin/kali $PREFIX/bin/kali-setup
```
